# FLOWIQ Project Changelog

## Version 1.0 - 27 September 2026

- Replaced the earlier VitaNova smart-campus project concept with FLOWIQ.
- Built a complete modular Python package around service-flow optimization.
- Added priority scoring, smart counter routing and waiting-time estimation.
- Added queue processing and simulated time advancement.
- Added what-if capacity simulation with NumPy analytics.
- Added counter capability-pair analysis with itertools and sets.
- Added OOP demonstrations: inheritance, overriding, encapsulation, class methods, static methods and operator overloading.
- Added automatic demo and no-dependency self-test.
- Added Markdown report, editable DOCX report and PDF report.
- Added presentation and Jupyter Notebook demonstration.
- Added single-file `FLOWIQ.py` for portals that accept only one Python file.
